# Responsibilities — Senior Front-End Developer

## Application Development

- **Build Modern Web Applications** — Design, develop, and maintain modern, scalable, responsive, and high-performance web applications using React, Next.js, and TypeScript.

- **Architect Frontend Solutions** — Architect reusable, maintainable, and extensible frontend solutions following industry best practices and modern design patterns.

- **Implement Next.js Patterns** — Build applications using Next.js App Router, React Server Components, Client Components, Server Actions, Route Handlers, Middleware, and React Router where appropriate.

- **Apply Rendering Strategies** — Implement modern rendering strategies including Server-Side Rendering (SSR), Static Site Generation (SSG), Incremental Static Regeneration (ISR), Streaming, and Partial Prerendering (PPR).

## UI & Design Implementation

- **Translate Designs to Code** — Translate UI/UX designs into clean, accessible, responsive, and pixel-perfect user interfaces.

- **Build Design Systems** — Develop reusable component libraries, shared UI packages, and design systems to improve consistency and development efficiency across projects.

## Performance & Optimization

- **Optimize for Quality Metrics** — Optimize applications for Core Web Vitals, SEO, accessibility (WCAG), bundle size, rendering performance, and overall user experience.

## API & Service Integration

- **Integrate APIs & Services** — Integrate REST APIs, GraphQL APIs, WebSockets, Server-Sent Events (SSE), and third-party services into the frontend application layer.

## Security

- **Implement Frontend Security** — Build secure frontend applications by implementing authentication, authorization, secure session management, OAuth, JWT, and modern frontend security best practices.

## Code Quality & Testing

- **Write Quality Code** — Write clean, modular, reusable, well-tested, and well-documented code following established engineering standards.

- **Maintain Test Suites** — Write and maintain unit, integration, and end-to-end tests using modern testing frameworks to ensure application reliability and maintainability.

## AI-Assisted Development

- **Review AI-Generated Code** — Review, validate, and optimize AI-assisted code to ensure it meets engineering standards for architecture, security, performance, maintainability, scalability, and code quality.

- **Evaluate AI Code Correctness** — Evaluate AI-assisted code for correctness; identify defects, performance issues, or security vulnerabilities; and refactor where necessary before production deployment.

- **Ensure AI Code Alignment** — Ensure AI-assisted code aligns with the project's architecture, coding standards, design patterns, and business requirements.

- **Leverage AI Tools Effectively** — Effectively leverage AI-assisted development tools to improve productivity while exercising sound engineering judgment and maintaining production-quality code.

## Technical Leadership

- **Own Technical Decisions** — Take ownership of frontend technical decisions, continuously improve architecture, reduce technical debt, and enhance developer experience.

- **Troubleshoot & Improve** — Troubleshoot production issues, identify performance bottlenecks, and implement long-term improvements.

- **Mentor & Review** — Conduct code reviews, mentor junior developers, and promote engineering excellence across the team.

## Collaboration

- **Cross-Functional Collaboration** — Collaborate closely with backend engineers, UI/UX designers, QA engineers, DevOps engineers, and product managers throughout the entire software development lifecycle.

- **Participate in Planning** — Participate in architecture discussions, sprint planning, backlog refinement, technical documentation, and continuous improvement initiatives.

## Continuous Learning

- **Stay Current** — Stay current with emerging frontend technologies, AI-assisted development workflows, and industry best practices; rapidly learn new frameworks using AI tools while maintaining high engineering standards.
