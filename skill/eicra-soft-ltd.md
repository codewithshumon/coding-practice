# Eicra Soft Ltd — Key Responsibilities

## Platform Engineering

- **Operate as a Generalist Engineer** — Contribute as a generalist engineer within a defined stack, working across both the internal cloud-native SaaS product and custom client integrations with equal proficiency.

## Microservices & API Development

- **Architect & Build Microservices** — Architect, build, and maintain scalable backend microservices and RESTful APIs using Node.js/TypeScript or Python/FastAPI, following clean architecture and testable design patterns.

## Database Design

- **Design Multi-Tenant Schemas** — Design advanced, multi-tenant schema isolation patterns and write optimized queries against PostgreSQL databases to support secure, scalable SaaS data architecture.

## Event-Driven Engineering

- **Engineer Event-Driven Workflows** — Engineer event-driven workflows utilizing AWS messaging and queue services (EventBridge, SQS, SNS) to enable reliable, asynchronous communication between microservices.

## Third-Party Integrations

- **Build Structured Connectors** — Build structured connectors to integrate complex third-party platforms, including ERP systems, eCommerce engines, and external data APIs into the SaaS platform.

## Cloud Infrastructure

- **Manage Shared Infrastructure** — Manage shared cloud infrastructure including caching layers (Redis), search engines (OpenSearch), file storage (S3), and API gateways to ensure reliability and performance.

## AI-Assisted Development

- **Leverage AI Tools Daily** — Leverage AI-assisted development tools like Claude Code on a daily basis to accelerate coding, automate refactoring, generate documentation, and improve overall development velocity.

## Asynchronous Collaboration

- **Collaborate Async with US Teams** — Collaborate asynchronously with US-based Solutions Architects via Linear, proactively participating in code reviews, maintaining strict engineering standards, and communicating clearly through written specs.
