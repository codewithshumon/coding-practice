# Impressive Security Limited — Key Responsibilities (Senior Software Engineer)

## Backend Development

- **Design & Develop Scalable Applications** — Design and develop scalable, secure, and maintainable backend applications using Node.js and NestJS, following modular architecture and SOLID principles.

- **Build & Maintain APIs** — Build and maintain RESTful APIs and third-party integrations with travel suppliers, payment gateways, airline systems, and external partner services.

- **Develop Travel Systems** — Develop flight booking engines, payment processing modules, supplier connectivity layers, and other travel-related backend systems that power the core platform.

## Performance & Security

- **Optimize Performance & Security** — Continuously optimize application performance for high-traffic scenarios, harden API security against common vulnerabilities, and tune database queries for efficiency at scale.

## Code Quality

- **Review Code & Maintain Standards** — Review pull requests, enforce coding standards, promote best practices, and maintain high development standards across the engineering team.

## Operations & Troubleshooting

- **Troubleshoot Production Issues** — Diagnose and resolve production incidents, perform root cause analysis, debug complex issues, and implement reliable, long-term solutions to prevent recurrence.

## Leadership & Collaboration

- **Guide Junior Developers** — Mentor and support junior engineers through knowledge sharing, constructive feedback, pair programming, and fostering a growth-oriented team culture.

- **Cross-Functional Collaboration** — Collaborate closely with frontend engineers, QA testers, and DevOps engineers to ensure seamless integration, thorough testing, and reliable deployments across the full software delivery lifecycle.
