# Codixel — Key Responsibilities (Senior Backend Developer)

## Data Pipeline Development

- **Build Event-Driven Data Pipelines** — Design and build event-driven data pipelines that process real-time financial news, from discovery and scraping through to classification and publishing.

## Backend Services & APIs

- **Develop Scalable Services & APIs** — Develop and maintain scalable backend services and APIs that power the earnings call platform, handling hundreds of events daily with reliability and low latency.

## Cloud Infrastructure

- **Integrate Cloud Services** — Integrate cloud infrastructure services for compute (Lambda, EC2, ECS), storage (S3, DynamoDB), messaging (SQS/SNS), and CDN delivery (CloudFront) to build a resilient, event-driven system.

## Data Modeling

- **Design Data Models** — Design data models for document databases (DynamoDB, MongoDB) and search engines (Elasticsearch) to support efficient querying, indexing, and retrieval across the platform.

## AI & LLM Integration

- **Implement AI/LLM Integrations** — Implement AI and LLM integrations for automated news classification, financial data extraction, event categorization, and conversational features powered by OpenAI, Anthropic Claude, and Google Gemini.

## Browser Automation

- **Develop Browser Automation Systems** — Develop browser automation systems using Playwright for recording live earnings call webcasts from various sources reliably and at scale.

## Audio Processing

- **Build Transcription Pipelines** — Build and maintain audio processing and transcription pipelines using WhisperX and FFmpeg for GPU-accelerated, word-level transcription with speaker diarization.

## Collaboration

- **Collaborate Across Teams** — Collaborate with infrastructure and frontend teams to ensure reliable, well-integrated system architecture across the entire platform.

## Performance & Reliability

- **Improve Platform Performance** — Continuously help improve performance, scalability, and reliability across the platform by profiling, optimizing bottlenecks, and implementing best practices.
