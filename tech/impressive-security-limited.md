# Impressive Security Limited — Technologies, Packages & Stacks

## Core Runtime & Frameworks

- **Node.js** — Asynchronous, event-driven JavaScript runtime built on Chrome's V8 engine, designed for building scalable, high-throughput network applications on the server side.
- **NestJS** — Progressive, opinionated Node.js framework with modular architecture, decorators, dependency injection, and first-class TypeScript support inspired by Angular.
- **TypeScript** — Strongly typed superset of JavaScript enabling static type checking, interfaces, generics, and superior tooling for large-scale backend codebases.
- **JavaScript** — Core dynamic scripting language powering the Node.js runtime for server-side application logic.

## Databases

- **MySQL** — Widely adopted relational database management system for structured data with strong read performance, replication support, and mature ecosystem.
- **PostgreSQL** — Advanced open-source relational database offering ACID compliance, complex queries, JSONB support, and robust extensibility.
- **Database Optimization** — Techniques including query tuning, indexing strategies, connection pooling, read replicas, and schema denormalization for performance at scale.

## Architecture & Infrastructure

- **Microservices** — Architectural pattern structuring an application as a collection of loosely coupled, independently deployable services communicating over lightweight protocols.
- **Redis** — In-memory data structure store used as a database cache, message broker, session store, and distributed lock manager for ultra-low-latency data access.
- **Queues** — Asynchronous message queuing systems (e.g., Bull, RabbitMQ) for decoupling services, handling background jobs, and managing workload spikes.
- **Caching** — Multi-level caching strategies (in-memory, Redis, CDN-edge) to reduce database load, lower latency, and improve throughput for frequently accessed data.

## APIs & Integrations

- **RESTful APIs** — HTTP-based API design following REST principles with proper status codes, versioning, pagination, filtering, and resource-oriented design.
- **Third-Party Integrations** — Integration with external vendors, payment gateways, travel suppliers, and partner services through APIs and webhooks.

## Travel-Specific APIs

- **Airline APIs** — APIs for flight search, booking, ticketing, check-in, flight status, and ancillary services from airline carriers and aggregators.
- **OTA (Online Travel Agency) APIs** — Aggregator APIs connecting to multiple travel suppliers for flights, hotels, car rentals, and ancillary services in a unified interface.
- **GDS (Global Distribution System)** — Travel industry distribution networks (Amadeus, Sabre, Travelport) connecting providers with travel agents for real-time inventory, pricing, and booking.
- **NDC (New Distribution Capability)** — IATA's XML-based data transmission standard enabling airlines to distribute rich content, ancillaries, and personalized offers directly through modern APIs.
- **Hotel APIs** — APIs for hotel search, room availability, rate plans, property information, and booking management from hotel suppliers and aggregators.
- **Travel APIs** — General travel-related third-party APIs covering ground transportation, activities, insurance, and other travel services.

## Security

- **API Security** — Practices including rate limiting, input validation, CORS policies, OWASP mitigations, API key management, OAuth 2.0, JWT authentication, and request signing.
- **Software Architecture** — Principles and patterns for designing robust, scalable, and maintainable backend systems including clean architecture, hexagonal architecture, DDD, and event-driven design.

## DevOps & Cloud

- **Git** — Distributed version control system for source code management, branching strategies, and collaborative development workflows.
- **Docker** — Containerization platform for packaging applications and their dependencies into lightweight, portable containers for consistent deployment across environments.
- **CI/CD** — Automated continuous integration and continuous deployment pipelines for building, testing, and releasing code reliably with minimal manual intervention.
- **Linux** — Open-source operating system powering server environments; proficiency in shell scripting, process management, and system administration.
- **AWS (Amazon Web Services)** — Comprehensive cloud computing platform offering services like EC2, RDS, ElastiCache, SQS, Lambda, and ECS for hosting and scaling backend infrastructure.
- **Cloud Platforms** — Cloud hosting and infrastructure services (such as AWS, Google Cloud, Azure) for deploying, scaling, and managing applications.
